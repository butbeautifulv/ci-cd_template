## Security Gate на MR/PR

Компоненты gate (параллельно):

- **SAST** — лёгкий/первичный в IDE; полный в CI
- **Линтеры** — style + security linters
- **Secret-check** — секреты в коде
- **Лишние файлы** — бинарники, запрещённые типы
- **SCA** — после SBOM на этапе сборки

Два варианта IDE SAST (из схемы):

1. Независимый плагин на ПК разработчика
2. Интеграция с корпоративным SAST (политики с сервера)

## Тестирование (QA / UAT) — детали с PDF

| Вид | Артефакты | Инструменты |
|-----|-----------|-------------|
| Unit-тесты | Корпус тестов | Test management |
| Фаззинг | Фаззинг-тесты, seeds | AFL++, Jazzer, go-fuzz |
| Concolic | Исходный код + корпус | спец. движки |
| Sanitizers | Сборки | ASan, Valgrind |
