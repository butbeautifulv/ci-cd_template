# Типовой процесс безопасной разработки для финтеха

> **Supplement** (ChatGPT view). Канон: [fintech-swimlane.md](../fintech-swimlane.md), [01-sdlc-process.md](../../01-sdlc-process.md). Источник: финтех PDF swimlane.

## Обзор

Документ описывает типовой SDLC/DevSecOps-процесс для финтех-систем с учетом требований безопасности, ГОСТ Р 56939-2024 и практик Secure SDLC.

## Входные данные
- Бизнес-требования

- Внутренние требования
- Требования ИБ
- Политики API

## Результаты
- Согласованные требования к ИС
- Архитектурные ограничения
- Задачи в трекере

## Роли
- Бизнес-аналитик

- Аналитик ИБ

# Специфика Bug Fix

Для bugfix-поставок допускается:

1. Минимизация ручного тестирования.
2. Упрощенный Security Gate.
3. Пропуск UAT.
4. Последующее проведение отдельных проверок.
